## 1. M4 复盘：八个问题（按严重性排序，证据齐全）

### 问题 1｜最关键：推理路径缺失预算锚——beam 深电路发散的直接根因（代码事实核实）

**`generate_routing.py` 与 `eval_policy.py` 的 beam 环境完全没有
`lambda_budget/sabre_swap_budget` 参数**（grep 零命中）。失败链：

```
训练时：r_c 含超预算惩罚（>1.05×SABRE 后每颗额外 SWAP 罚 0.5）
        → V_LA 的 expectimax 目标在"预算约束下的回报"上训练
推理时：beam 的 r_c 无任何预算惩罚 → 超预算零成本
        → V_LA 被用在训练时从未见过的"无约束奖励分布"上打分
```

数据吻合：6 条 TRUNC 电路的 beam5la SWAP **全部 982-990 顶格**（9-25× SABRE），
而其中 5 条 argmax 本可正常完成（77-339 SWAP）——**beam 把正常电路推爆**。
这是可修的工程缺口而非机制失败：beam5la 在完成的 13 条上很强
（rc_adder_6 +204%、tof_3 +23% vs SABRE）。

### 问题 2｜V_LA 尺度/语义口径缺陷

训练目标 `la_val` 在 batch 内归一化（每个 batch 的 mean/std 漂移），推理打分
`Score = r_c + γ·V_LA` 直接混用原始尺度 r_c——**V_LA 在 beam 排序里实际只当
tie-breaker**。+5.9% 是在"V_LA 被压制"条件下取得的；尺度对齐后可能更好
（也可能放大误估）——未消融，已知未知。

### 问题 3｜训练-推理 beam 配置不一致

训练 anchor **B=3/K=2**（3 候选 2 步展开），推理 **beam5/深度 1**（5 候选 1 步）。
V_LA 学的是"3 候选语境下的 2 步 expectimax 值"，推理时给"5 候选的 1 步后继"
排序——分布有偏。

### 问题 4｜actor 未内化前瞻（纯 LA 贡献仅 +1.1%）

- FTC 归因：argmax +6.9% 中 **+5.8% 来自单纯继续训练**，LA 纯贡献 +1.1%
  （v1 设计上不动 actor 梯度，既定代价兑现）；
- **agreement 仅 0.15-0.34 且无上升趋势**；
- **vla_loss 无下降**（0.99 → 0.96-1.02 平台）：目标自举 + policy 移动 →
  学习信号质量存疑。

### 问题 5｜SWAP 纪律仍失守（4×）

argmax 176.4 vs SABRE 43.5；训练全程 G1 报警（sr 1.2-2.4）。绕路失败实证：
gf2^6 用 339 SWAP（3.1×）只换到 0.0253 < SABRE 0.0344——绕路决策前瞻深度不够
（K=2 vs SABRE 等效 20 门 extended set）。

### 问题 6｜固化游走未修复（KL 锚的已知代价）

hwb6/mod_red_21 argmax 990-SWAP 游走原样保留（KL 锚不允许策略跑远修固化失败模式）。

### 问题 7｜单种子归因置信度

LA−FTC 的 +1.1% 在单种子（seed=0）下无法排除 KL 微调自身种子方差。

### 问题 8｜logmean 悬殊（0.0175 vs 0.0863）

结构性优势集中在 gf2/tof 族；csla_mux_3/gf2^6 仍大败——深电路优势未覆盖全部模式。

## 2. 行动计划（按性价比排序）

### A1｜推理侧预算约束（eval 版 P1-a）——✅ 已完成（2026-09-17，含两次机制修正）

**实施中的两次机制修正（关键教训，比预期曲折）**：

| 版本 | 机制 | tof_10 探针 | 结论 |
|------|------|------------|------|
| v0（原计划） | env 传 `lambda_budget` 惩罚 | 982 TRUNC 不变 | **空操作**：beam 每步所有候选都 +1 SWAP，`swaps−budget` 对所有候选相同 → 常数项不改排序；V_LA 观测无预算状态 → 价值项也不知道超支 |
| v1 | 惩罚 × "未解锁门"进度 | 982 TRUNC 不变 | **进度信号太稀疏**：深电路大部分步骤 top-5 候选全不解锁门 → 惩罚退化为常数 |
| **v2（定稿）** | 惩罚 × **(门解锁 OR Φ 改进)** | **completed, 124 SWAP** | Φ 改进（距离改善）稠密得多，有效打击游走决策点 |

定稿机制：超预算（`swaps > 1.05×SABRE`）状态下，**既未解锁门、也未改善 Φ 的候选**
按超支深度受罚（`score -= λ_budget × over_by`）；解锁门或改善距离的候选豁免。
代码落点：`generate_routing.py`/`eval_policy.py` 的 beam 打分循环 +
`--lambda-budget/--budget-delta` CLI（默认关=历史口径）。

**A1-reval 结果**（NAM × tianyan287_20q，T=64/32/16，seed=42，λ=0.5/δ=1.05）：

| method | fid_mean | logmean | SWAPs | TRUNC |
|--------|----------|---------|-------|-------|
| SABRE | **0.2461** | **0.0863** | 43.5 | 0/19 |
| LA287 argmax | 0.2392 | 0.0175 | 176.4 | 2/19 |
| LA287 beam5la（修复前） | 0.2316 | 0.0002 | 375.7 | 6/19 |

- ✅ **发散修复**：TRUNC 6→1（唯一残余 mod_red_21 为起点固化游走）；SWAPs −64%；
  logmean 改善 30×；5 条深电路从 fid=0 修复至 0.01-0.14；
- ❌ fid_mean ≥0.24 未达（0.2341 最高）：发散修复收益被预算副作用抵消

- ⚠️ **G9 翻转**：预算口径下 route 头反超 V_LA 头（0.2341 vs 0.2314）——

- **新教训：预算锚的固有张力**——固定 δ 不分"必要绕路"与"无效游走"→
  budget-delta 消融（1.05/1.5/2.0）或自适应锚（以 argmax SWAP 为基准）列入后续。

**设计**（20260916 方案 §5 v2 锚定的落地）：

## 2.6 蒸馏的通道语义：为什么执行顺序必须是 A1 → A1' → A2 → A3

> 本节回答：蒸馏到底修什么、V_LA 的缺陷如何污染学生、为什么"让老师先正确"不是
> 偏好而是必要条件。这是 A3 启动前的方法论依据。

### 2.6.1 蒸馏修的是"排序差"——两个排序、两个方向

同一状态 s 的候选动作集上有两个排序：

| 排序 | 来源 | 学到的语义 |
|------|------|-----------|
| **π 的排序** | actor logits | 单步优势（PPO advantage），即时回报主导 |
| **V_LA 的排序** | expectimax Q(a) = r + γ·max Q(child) | 多步可达回报 |

**排序差** = 两排序不一致的决策点，度量即 agreement（0.15-0.34：66-85% 的 anchor
步上 actor 第一选择 ≠ beam 第一选择）。蒸馏 `L = −λ_d·log π(la_act|s)` 做的事
非常具体：**把 V_LA 排序的第一名搬运到 π 排序的第一名**——它不产生任何新评估
知识，V_LA 一分不改。因此：

- **方向 1（策略错、老师对）→ 蒸馏收益**：barenco_tof_3 的 6 个分歧点全部在
  argmax top-5 内（可达性 100%）；G9 的 +5.9%；
- **方向 2（策略对、老师错）→ 蒸馏污染**：G9 翻转的实证——预算语境下 la 头在
  tof_4（0.3165 vs 0.7092）、tof_5（0.2891 vs 0.5523）、gf2^5（0.0252 vs 0.0650）
  上排序劣于 route 头。这些电路上蒸馏，学生学到的是老师的错误排序。

### 2.6.2 缺陷 A（预算语境）如何沿 la_act 传染——三层事实链

1. **V_LA 从未"看见"预算状态**：观测 = [GNN 嵌入×3 + sabre5 + look4 + noise5]，
   不含 `swaps_so_far/budget`。训练时预算惩罚确实在 r_c 里、进了 expectimax 目标——
   但同一观测状态在不同 episode 对应不同预算状态（目标不同、输入相同）→ 对 V_LA
   这是标签噪声 → 它只能学到对预算状态的平滑平均，无法区分"超支 5 步"与"超支 500 步"；
2. **实测放大（G9 翻转）**：预算惩罚活跃区段 V_LA 排序系统性劣于 v_route（见上表）；
3. **代码级缺口（新发现，A1'）**：v2 蒸馏的训练 anchor 用 `lookahead.py` 的
   `beam_expectimax`，其 Q = r_c + γ·max Q **不含** A1 的"超预算×无进展"排序惩罚
   （那只加在了 `eval_policy`/`generate_routing` 的推理 beam 里）——**训练期老师的
   排序与部署期搜索的排序是两个口径**，蒸馏前必须同步。

传染链条：蒸馏在超预算状态下，la_act = V_LA 偏好（预算盲视）→ 学生模仿 → 策略在
超支状态的单步决策继承盲视 → **A1 刚在 beam 层修好的发散行为，以 argmax 的形式
从策略里长回来**。

### 2.6.3 缺陷 B（尺度口径）——γ 折扣语义失效的数值例子

训练时 `la_val` 在 batch 内标准化（`la_val_n = (x−mean_b)/std_b`），V_LA 输出的是
无量纲量；推理打分 `Score = r_c + γ·V_LA` 直接混用原始尺度 r_c（步级 ±0.1-1）。
问题不是"单位不同"本身，而是**混合权重随 batch 成分漂移**：

- 设候选 a/b：r_c = +0.3/+0.1，真实未来回报差 = 9（b 远优）。正确排序应被未来主导；
- 若该 batch σ_b=3 → V_LA 输出差 3 → 未来的权重被压缩 3 倍（短视偏置回来）；
- 若 σ_b=0.5 → 输出差 18 → 未来被过度加权 2 倍（眼前 reward 失效）；
- 同一模型、不同 batch、不同的"未来 vs 眼前"有效权重——beam5la+bud 在不同电路
  区段忽好忽坏（赢 csla_mux_3/mod_mult_55，输 tof_4/tof_5/gf2^5）与此一致。

传染路径：la_act 是这个失准混合物 argmax 的产物 → 学生模仿 → 策略 logits 被拉向
V_LA 的怪异尺度；且 **GNN 主干共享**（LA287 实测主干外溢：beam5r 也 +13.1%），
扭曲会同时污染 v_route。

### 2.6.4 为什么顺序不可颠倒：蒸馏是单向放大器

| | PPO（value/policy 协作） | 蒸馏（teacher/student 单向） |
|---|---|---|
| 老师错了怎么办 | return 会纠正 V（MSE 项） | **无纠正机制**，la_act 就是标签 |
| 错误的生命周期 | 被下一批 return 覆盖 | 进入策略权重，被 KL 锚**固化** |
| 对噪声的敏感度 | advantage 均值化吸收 | 逐样本模仿，噪声直通 |

时序放大效应：微调前期是策略习惯形成最快的窗口（lr 未衰减、KL 未收紧）。老师带
缺陷开局 → 学生在缺陷方向形成习惯 → KL 锚定把习惯锁死 → 之后老师自我修正
（policy 变强 → beam 候选变好 → la_act 变好）也改不动学生——**先错误的蒸馏 +
后锁定的 KL = 把 bug 写进宪法**。

经济学：让老师变正确的成本 ≈ 零——A1 已完成；A1'（惩罚同步进 beam_expectimax）
~10 行；A2 推理校准 = 存两组常数 + 5 行（raw-target 选项反正并入 v2 重训）。
反过来先蒸馏：100k × 2 的预算消耗在"模仿已知有缺陷的老师"上，产出可疑，且坏习惯
被锁后的修正成本远超当初。

### 2.6.5 "老师正确"的验收判据（可操作定义）

| 判据 | 度量 | 通过线 |
|------|------|--------|
| 预算语境修复（A1'） | 预算口径下 la 头 ≥ route 头（G9 恢复） | beam5la+bud' ≥ beam5r+bud（当前 0.2314 < 0.2341，需翻转） |
| 尺度对齐修复（A2） | 校准后同 ckpt 对比 | 校准口径 ≥ 归一化口径，且 tof_4/tof_5 类区段损失消失 |
| 目标-部署一致性 | `beam_expectimax`（含 A1 惩罚）的 la_act 与部署 beam 逐步选择一致率 | 高一致（同一排序逻辑） |
| 老师质量总检 | beam5(la)' 的 fid_mean | ≥ argmax 0.2392（老师值得模仿的底线） |

四条全过 → 老师在预算语境、尺度口径、目标-部署一致性、绝对质量上全部站住 →
蒸馏的每一条 la_act 都是"方向 1"样本，方向 2 污染通道关闭。

```
v1（已完成）  beam_expectimax ──la_val──► V_LA 头        （G9 ✅：更好的打分器）
                           └─la_act──► agreement 诊断     （0.15-0.34 = 排序差 = 蒸馏空间）
A1（已完成）  推理 beam + 预算×Φ进度惩罚 ──► 发散修复 6→1
A1'（v2 前置）A1 惩罚同步进 beam_expectimax ──► 训练/部署同口径
A2（下一步）  尺度校准 / raw-target ──► γ 折扣语义恢复
A3（v2 蒸馏） la_act ──► −λ_d·log π(la_act|s) ──► argmax ≈ beam5(la)
              前提：A1'+A2 全过 → 方向2 污染通道关闭 → 学生只模仿"方向1"样本
              终态：train-inference mismatch 从定义上闭合
```

## 7. 一句话总结

LA287 证明了训练期 beam 的机制价值（G9 ✅），beam 深电路发散已由 A1 修复
（TRUNC 6→1，核心教训：常数级预算惩罚不改 beam 排序，必须与候选特异的
Φ-改进进度交互）；但 V_LA 的两个已实测缺陷（预算语境盲视、尺度口径漂移）会经
la_act 单向传染给策略并被 KL 固化——蒸馏是零纠错的排序搬运，所以执行顺序不可
颠倒：先 A1'（训练期老师与部署同口径）+ A2（尺度对齐）让老师通过"正确性四判据"，
再以蒸馏把前瞻内化进 argmax，目标：argmax ≥ 0.2392 且 beam5(la) 无发散、
逼近/超越 SABRE 0.2461。
