## 一、MDP 语义：事件时钟 + launch/advance

**不采用固定时长周期网格**（tick=CX 会使 1Q 时长夸大 8.6 倍、rz(0us)/measure(2.0us=6.67 tick)
无处安放、等一个 SWAP 需 ~25 次无意义 SKIP、重叠窗口量化破坏与模拟器逐 us 记账的一致性）。
采用**连续物理时间 + 事件推进**：

| 概念 | 定义 |
|---|---|
| 时钟 T | 全局连续事件时间（us），复用 `CircuitTiming.total_time` |
| launch | EXEC/SWAP 一律**从当前 T 起跑**（硬锁语义，非排队），锁时长 = 真实门时长 |
| **周期**（隐式） | 两次 SKIP 之间 launch 的动作集合 = 一个并发波；长度由波内最长动作决定 |
| **SKIP** | 推进 T 到**下一完成事件** `T' = min{busy_until[q] : busy_until[q] > T}`，结算所有 `end==T'` 的动作 |
| SWAP 映射生效 | **launch 即交换 mapping** 并锁端点 0.9us——物理正确性由锁保证（锁释放时 SWAP 已完成） |
| 并行模式 | 1) 同 T 连续 launch（同波并发）；2) SKIP 到中间完成点后，在飞长动作（SWAP）尾部窗口内 launch 新动作 |

时间线示例：

```
T=0.0   launch SWAP(2,3)[锁到0.9] + CX(0,1)[0.3] + CX(4,5)[0.3]   <- 同波并发
SKIP -> T=0.3   两个CX完成，q0/1/4/5解锁
        launch CX(0,4)[0.6]     <- 与SWAP尾窗[0.3,0.9]重叠 = "填SWAP窗口"模式
SKIP -> T=0.6   CX(0,4)完成
SKIP -> T=0.9   SWAP完成，q2/3解锁，frontier更新
```

SWAP 不"占 3 个时钟周期"——它占用 0.9us 连续物理时间；时钟每次推进都对应真实完成
事件，无空转决策点。**事件时钟 = 固定网格删掉所有空 tick**。

### 1.1 编译语义 vs 物理语义（显式区分）

- `logical_mapping`（env 的 `self.mapping`）：**编译器计划状态**，SWAP launch 时更新
- `physical_busy`（`timing.busy_until`）：**物理可用状态**，动作完成时更新

代码注释与论文口径统一此命名；不变量测试：schedule_log 中每个门事件的
`start >= 同 qubit 全部前序事件的 end`（物理互斥）。

### 1.2 合法性检查（显式三段，不做等价合并）

```
EXEC(g) 合法 <=> DAG_ready(g) 且 physical_free(M(q_i)) 且 physical_free(M(q_j)) 且 adj(M(q_i), M(q_j))
```

> 不做 "physical_free => DAG_ready" 的优化合并。二者在当前 `from_circuit`
> （preds=last_on_qubit）+ 映射双射下**恰好**等价，但这是依赖两个结构不变量的
> 脆弱等价（未来加 commutation 重写即破）。三段检查全部 O(1)——用 3 行代码
> 换掉一个隐式依赖。

### 1.3 1Q 惰性物化（lazy materialization）

1Q 门不进动作空间、不急迫执行。触发物化仅三种情况：

1. **EXEC(g) launch**：自动物化 g 两条逻辑比特上的未物化 1Q 尾链（从 T 起依次排列，
   rz=0）；EXEC 锁时长 = 尾链 sum(dur(1Q)) + 0.3us
2. **SWAP launch 不触发物化**（SWAP 是物理操作、不消费逻辑门）→ 保留
   "先 SWAP 后 1Q 换位到更优位置"的自由度（量化价值 ~0.1% 保真度，零成本保留）
3. **终局**：所有 2Q 完成后，尾部 1Q + measure 波自动物化于最终映射位置，随即 done

不变量：任何门 launch 前其 DAG 祖先已物化；"不是动作" != "不可见"——1Q 的时长、
idle、single_q_err、35ns 重叠窗口全部照计入调度内核与奖励。

### 1.4 终止与进展保证

- done：全部 DAG 2Q 门 completed → 尾部波自动物化 → done（makespan = 尾部波结束）
- SKIP 合法 <=> 存在 busy_until > T（有在飞动作）；无在飞时 SKIP 被 mask，必须 SWAP/EXEC
- **liveness 规则**：若 mask 后零合法动作 → 依序放松死锁 mask → 放松 unmapped mask；
  每步断言 >=1 合法动作
- 防游走：`no_progress_limit` 改为"连续 SKIP/SWAP-launch 无任何完成事件"口径；
  `swap_history` 震荡 mask 沿用

## 三、动作空间

统一词表 `Discrete(E + K + 2)`，phase mask 切换：

```
[0, E)      SWAP(e)    合法：端点空闲 且 双端被占用 且 非死锁mask
                       （get_unmapped_mask + get_deadlock_mask 沿用）
[E, E+K)    EXEC(g)    合法：g 属候选集 且 三段检查通过（§1.2）
E+K         COMMIT     仅映射阶段合法（commit_head 沿用）
E+K+1       SKIP       合法：存在 busy_until > T（有在飞动作）
```

### 3.1 候选集与 priority-K（评审六采纳）

- 候选集 = ready 且 相邻的 2Q 门；**按 priority 排序取前 K，不用 gate index 排序**：

```
Priority(g) = alpha * criticality + beta * future_demand + gamma * ready_age
```

（三项均为已计算特征，零额外成本；delta*SABRE_score 不加——SABRE score 无 per-gate 口径，
且三项已消除 index 的任意性。）

- K = 24（`--max-ready-2q`，CLI 可调），pad+mask；**locked 门进槽位但 mask**（槽位语义稳定）
- **截断率实测**：NAM 19 条 DAG frontier max=6（p99=3）、indist 50 条 max=10（p99=5），
  K=24 截断率 **0.000%**——当前 20q 无风险，此机制为 60q 预埋（frontier 可达 20-30+）

### 3.2 覆盖率监控（评审七采纳，便宜口径）

不做 oracle-best 版（需 per-action Q，循环且贵）；C0 metrics 记录
`|candidates| 分布 + 截断率 = 1 - min(1, K/|cands|)` 的事件比例。>1% 即升级 K 或 priority。

### 3.3 映射阶段兼容

词表/奖励/观测与现状完全一致：EXEC/SKIP 头 mask，timing 特征全零（映射期无时钟）+
载入时新列零初始化 → **旧 checkpoint 映射行为逐位不变**。

## 四、锁机制

- 唯一锁源 = `busy_until[P]`（CircuitTiming 已有）；EXEC 锁 = 1Q 尾链 + 0.3us，SWAP 锁 = 0.9us
- 三段合法性检查（§1.2），不做 "preds 完成 <=> 端点 free" 的等价合并
- 无死锁：launch 只占不等待，SKIP 保证进展；两动作共享 qubit 由锁互斥，
  SWAP 与 EXEC 并发仅限不相交 qubit（与 v3 动态串扰的"不相交并发对"口径一致）
- 防游走：no_progress_limit 新口径（§1.4）+ 死锁 mask 沿用 + liveness 兜底

## 五、奖励函数（v3 口径，评审十二采纳）

### 5.1 通道分解表（奖励项与 v3 噪声通道一一对应）

| v3 噪声通道 | 位置 | 奖励对应 |
|---|---|---|
| depol2 + thermal + **静态 ZZ theta_pq**（CX 自边） | `_run_actions` L428-440 | EXEC：`B - e_edge - w_zz*theta_pq - w_xt*theta_marg` |
| 3x(depol2+theta) + thermal(0.9)（SWAP 自边） | L416-427 | SWAP：`-swap_price_scale*3*(e_edge + w_zz*theta_pq)` |
| **动态 ZZ：门x门 + 门xSWAP + SWAPxSWAP**（v3 开启，rate x overlap，不相交并发对） | `_prepare_events` L323-357 | **EXEC 与 SWAP launch 都付边际 theta**（0.9us 窗口为主导项） |
| idle 间隙 thermal（逐 us 逐比特，事件前结算） | L408-415 | SKIP：`-eta_idle * delta_idle` |
| always-on ZZ（双空闲耦合对，**v2/v3 默认关**） | L360-373 | `-eta_ao`，与模拟器同 flag 联动，默认关 |
| depol1 + thermal（1Q） | L441-447 | 物化时计入（小项，pot_1q_reward 开关沿用） |
| 终端 | — | `lambda_F * (log F - log F_sref)`，F = **v3** fidelity_events(env schedule_log) |

关键事实（源码核实）：v2/v3 **收取** idle 间隙热退相干（L413-415，每事件起点对
`start - t_last_end[q]` 施加 thermal）→ eta_idle 是 sim-aligned，非 phantom。

### 5.2 theta_marginal 定义与可加性引理（本方案信用分配基石）

```
theta_marginal(a) = sum_{b 属 在飞动作, overlap(a,b)>0}
                    sum_{(x,y) 属 Qa x Qb, x!=y, adj(x,y)} (theta_xy / t_2q) * overlap(a,b)
```

- rate = theta_xy/two_gate_time，与 v3 `_prepare_events` 同式；swap 参与对（v3 口径）
- **可加性引理**：每对重叠动作 (a,b) 恰在第二个 launch 时计费一次 →
  `sum_launches theta_marginal = sum_pairs theta_pair = v3 编译的 zz_actions 总角`
  ——逐动作串扰奖励之和与模拟器总 ZZ 注入角严格相等（对 0.02% 教训的结构性修复）
- **必须单测锁定**：env 自算边际 与 v3 zz_actions 总角逐对相等（含 swap 对）

### 5.3 SKIP 定价（反 stall）与机会成本惩罚的拒绝（评审十/十一）

- SKIP idle 结算：`r_skip = -eta_idle * [sum_{q 空闲且激活}(T'-T) + sum_{q 于(T,T']完成}(T'-end_q)]`
  ——空转有价，天然反 stall；等待的真实物理成本同时进入奖励与终端保真度两端
- **拒绝**"有合法 EXEC 却 SKIP 罚更重"的机会成本机制，理由：
  1. 直接惩罚含义 B（故意等待避 ZZ/换并发）——那是本设计存在的全部理由，
     会把策略偏置回永远 ASAP，等于建了时钟化动作空间又教它别用时钟
  2. avoidable_idle 与 eta_idle double-count（等待的物理代价就是 idle 退相干本身）
  3. Q-based 机会成本需 per-action Q 头（现架构只有 state-value critic），成本高、新偏差源
- 防线（替代方案）：eta_idle 按 v3 敏感度回归校准（与 swap_price_scale=4.6 同一套审计）+
  no_progress 截断 + C0 makespan 门槛监控 + SKIP 率指标。若 C0 出现拖时间策略，
  先修校准，不动机制

### 5.4 沿用项

- R3 势函数 shaping：每步 `r += gamma*Phi(s') - Phi(s)`（策略不变性保持，时钟化步语义无关）
  ——即评审五要的 `-delta H_SABRE` 路由信号，**已存在无需新设计**
- P1-a 预算锚：SWAP 超预算 `-lambda_budget` 沿用
- 截断：`-unfinished_penalty * remaining` 沿用
- **校准声明**：swap_price_scale=4.6 为 v2 口径（20260917 审计），v3 下 SWAP 边际保真度
  成本 = 固定基价 + 随重叠上下文变化的动态项，需在 Step 0 重推导

| 受控重叠 SWAP（SWAP+相邻门，扫 overlap） | w_xt（边际串扰价） |
| 受控 idle 间隙扫描 | eta_idle |
| 单 CX 静态 ZZ / e_edge 扫描 | w_zz |
| （记录项）v2 vs v3 在 swap 密集族的保真度差 | headroom 预期 |

### C0：调度 warm-up（冻结 edge 头 + GNN，只训 gate/skip 头）

- BC 蒸馏（auto-batch 教师）+ 奖励：`R = B*progress - eta_time*deltaT + lambda_par*R_parallel - swap价`
- **修正说明**：评审原案 R_0 = -deltaT + lambda_par 无 EXEC 即时信号，重蹈 R2 教训
  （纯终端/延迟信号在长 horizon 上失败），保留 progress 项 B
- 门槛（不过则停线排查，不盲目进 C1）：
  - 批效率 >= LA287core 的 90%
  - makespan <= SABRE+D2 的 1.5 倍

### C1：routing 解冻

- 全参数解冻，R3 Phi shaping（= -delta H_SABRE 语义，已存在）
- 启动 edge-logit 秩相关监控（§6.3）

### C2：+ 局部噪声

- 边际 theta（含 swap 对）+ idle 价 + 静态 ZZ 价，全部 Step 0 校准值

### C3：噪声感知终端

- v3 events 保真度，log-ratio vs SABRE+D2@v3 sref；lambda 调度沿用 t287 配方

**诊断包**（C0/C1 全程记录）：frontier 分布与截断率、SKIP 率、makespan、
批效率、edge-logit 秩相关。

**成本估计**：参照 train.md 20q 实测（40k 步约 30 分钟/单卡），时钟化每步开销约
1.5-2 倍（episode 更长、obs 多 gate 块），C0-C3 全程单卡约 4-8 小时。

## 十、风险与回退

| 风险 | 缓解 / 回退 |
|---|---|
| 步数 x5-7（launch+SKIP vs 纯 SWAP 步）→ 信用分配 | 自适应 GAE lambda（已有）+ 逐步即时价格；仍不稳 → **EXEC-ALL 宏动作补丁**（词表 +1，一步发射全部合法 EXEC，恢复旧批语义捷径；用户确认仅作回退预案） |
| gate 头冷启动漂移 | C0 冻结 edge+GNN + auto-batch 蒸馏双保险 |

| 保真度/SWAP trade 恶化 | 子类隔离，--no-clocked 旧路径零改动回退 |
