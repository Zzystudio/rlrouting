# 训练方案：0915 底座 × 训练期 Beam Lookahead（2026-09-16 v2 定稿）

> 目标：在 **0915 方案全部组件**（tianyan287_20q 子拓扑、P0 奖励设计、S5 训练集）之上，
> 引入**训练期 beam 搜索**（V_LA 多步价值头 + expectimax 目标），解决 p0t287 在 NAM
> 基准上暴露的两个问题：① argmax 总口径落后 SABRE（0.2237 vs 0.2461）；② **beam5
> 推理发散**（7/19 TRUNC，推理端裸 beam 在 t287 势函数景观下不可用）。
> 方法论约束（沿袭 0915）：**价格/奖励全面冻结**（与 p0t287 训练逐字一致，只加训练
> 算法级 beam 机制）；**单变量纪律**（对照组隔离"继续训练"与"beam 注入"的贡献）。

## 1. 现状诊断（2026-09-16 新鲜证据）

### 1.1 p0t287 的 NAM 基准表现（GPU 加速评估，T=64/32/16 seed=42）

| 口径 | SABRE | p0t287 argmax | p0t287 beam5 |
|------|-------|---------------|--------------|
| Fid mean | **0.2461** | 0.2237 | 0.1508 |
| logmean | **0.0863** | 0.0061 | 0.0001 |
| SWAPs mean | 43.5 | 236.8 | 420.9 |
| TRUNC | 0/19 | 3 条游走（swaps ~990，fid=0） | **7/19 TRUNC** |

**T=128 深电路复核**（GPU，≥12q 七条）：p0t287 argmax **4 胜 3 负** SABRE
（gf2^5 +39% / gf2^6 +25% / barenco_tof_10 +49% / tof_10 +20%；负 csla_mux_3、
rc_adder_6（游走）、≈ gf2^4）。

### 1.2 两个问题的定位

| 问题 | 证据 | 根因 |
|------|------|------|
| **beam5 发散** | 7/19 TRUNC，完成者多数劣于 argmax；与 R3b（beam5 +2.8%）方向完全相反 | 推理端 beam 打分 `V(s')=v_route+λv_fid` 在 t287 势函数景观下对深电路系统性误估，beam 把单步误差放大成整轨迹发散；预算锚/反游走不在推理路径上 |
| **argmax 深电路"SWAP 换保真度"** | gf2/tof 族以 2-4× SWAP 代价换 +20~49% 保真度 | P0 边噪声注入真实生效，但策略**无前瞻**——无法用少 SWAP 的路径达到同样的边质量，只能暴力绕路 |

**核心论点**：模型已经"知道"什么样的边好（P0 注入生效），缺的是**用更少 SWAP
达成同样目标的前瞻规划能力**。这正是训练期 beam lookahead 要注入的能力——
并且推理端裸 beam 已被证伪（发散），**beam 必须在训练时进入学习闭环**。

### 1.3 train-inference mismatch（总纲，沿用）

训练目标是单步策略梯度（`a_t → r_t`），推理目标是多步搜索最优
（`argmax Σ γ^t r_t`）；SABRE 的 `H = H_front + W·H_extended` 天然为 lookahead
服务。V_LA（expectimax 多步价值头）是语义上与 beam max 算子匹配的打分器，
取代挂账的 fid-critic（零初始化后从未训练）与深电路误估的 v_route。

### 2.4 本轮唯一增量：训练期 beam lookahead

```
训练期 rollout（anchor 步：routing phase，每 --la-interval 步一次，episode 内 cap）：

  s_t ── GNN ──► Actor logits ──► top-B 候选 SWAP
                       │
           ┌───────────┴───────────┐
           ▼      (env.clone × B)   ▼
     depth 1: r¹_c, s¹_c ────► 再展开 top-B（depth K=2）
           │                            │
           ▼                            ▼
    叶节点批量 GNN forward ──► V_LA(s_leaf)     ← Multi-step Critic
           │
   Expectimax 回溯：Q(a)=r+γ·max Q(child)，done/trunc 节点 Q=r_c
           │
   ┌───────┼──────────────┐
   ▼       ▼              ▼
 la_val  la_act        agreement
（V_LA 回归目标）（诊断）  （actor-beam 一致率）
```

PPO 本体（采样动作、GAE on v_route）**完全不动**；lookahead 只以附加 value loss
+ 新价值头注入。V_LA 回归 expectimax 目标：

```
V_LA(s_t) ← max_{a∈topB} [ r(s_t,a) + γ·V_child(s_{t+1}(a)) ]
V_child(s) = 0 (done/trunc) | V_LA(s)（depth K 叶，自举）| max_{a'} Q（中间节点）
```

推理打分：`Score(s_c) = r_c + γ·V_LA(s_c)`——r_c 已含全部 0915 定价项
（potential progress、3×e_edge SWAP 价、Φ shaping、w_xt_swap、调度项），零新增权重。

**不改 PPO advantage 公式**（max-return 与 E_π-return 混算会注入乐观偏置）：
v_route 照旧 on-policy GAE（稳定性的锚），V_LA 独立头（零初始化，仿 critic_fid 先例）
专司 beam 打分——**V_LA 本身就是 Multi-step Critic**。

## 3. 训练路径：KL 锚定微调（主）+ 对照

### 3.1 路径选择

| 路径 | 评估 | 结论 |
|------|------|------|
| **KL 锚定微调（p0t287 起点）** | 观测配置与 p0t287 **完全一致**（edge 特征同构，checkpoint 全兼容）；唯一新参数是零初始化的 critic_la 头；奖励逐字不变 → KL 锚（G5）下微调退化的主因（奖励/观测变化）不存在；beam 机制是训练算法级改动，KL 微调正是其适用场景 | ✅ **主路径** |
| 从零训练 | t287 从零已两次失败（t287-v1/v2），40-60% 种子失稳率 | 仅作 fallback |

微调语义澄清：t287sh 微调失败是**奖励变化**导致；本轮奖励/观测零变化，
唯一变量是训练期 beam——KL 锚定微调的正确适用场景。

### 3.2 实验矩阵

| Run | 起点 | LA | KL 锚 | 步数 | 目的 |
|-----|------|----|----|------|------|
| **LA287**（主） | p0t287 | `--la-beam 3 --la-depth 2` | P2C β=0.05 | 100k | beam 注入 |
| **FTC287**（对照） | p0t287 | `--la-beam 0` | P2C β=0.05 | 100k | 隔离"继续训练"贡献（区分 LA 与单纯多训） |
| p0t287 | — | — | — | — | 已有 NAM 全数据（§1.1），零成本基线 |
| SABRE | — | — | — | — | 已有数据 |

（40-60% 种子失稳主要是从零训练现象；KL 微调历史上稳定，暂不单开种子预算，
若 LA287 异常退化再补 FTC 同种子复跑归因。）

### 3.3 训练命令（tmux 双会话并行，不同 GPU）

```bash
# tmux: la287（GPU0）
cd src && python3 -m routing.rl.train_agent \
  --topo ../traindata/topo/tianyan287_20q.json --max-num-qubits 20 \
  --reward-mode routing --split-prefix unified --use-scheduler \
  --reward-potential --pot-progress-b 0.20 \
  --edge-noise-features --beta-noise 0.5 \
  --w-err 0.02 --w-xt 0.01 --w-xt-swap 0.02 \
  --shaping-gamma 0.99 --eta-shape 0.3 --alpha-ext 0.5 \
  --eta-xtalk 0 --eta-parallel 0 --unfinished-penalty 0.3 --eta-time 0.05 \
  --no-progress-limit 200 --eta-xtalk-par 1.0 --eta-idle 0.005 \
  --lambda-budget 0.5 --budget-delta 1.05 \
  --nam-circuits-dir ../traindata/gen_structured,../traindata/gen_structured_v2 \
  --nam-circuit-prob 0.3 \
  --noise-hetero "0:0.4,1:0.3,2:0.3" \
  --qasm-stage-cap "stage1:6,large_n8:10,large_n10:12,large_n12:14,large_n16:20,large_n20:20,unified:20" \
  --curriculum-keys 'stage1,large_n8,large_n10,large_n12,large_n16,large_n20,unified' \
  --load ../models/policy_p0_t287.pt \
  --teacher ../models/policy_p0_t287.pt --variant P2C --beta-kl 0.05 \
  --la-beam 3 --la-depth 2 --la-interval 4 --la-max-anchors 128 --la-vf-coef 0.1 \
  --checkpoint-dir ../models/ckpts_LA287 --timesteps 100000 \
  --out ../models/policy_LA287.pt --device cuda:0 --seed 0

# tmux: ftc287（GPU1）：同上，去掉全部 --la-* 参数
#   --checkpoint-dir ../models/ckpts_FTC287 --out ../models/policy_FTC287.pt --device cuda:1
```

（`--la-interval` 最终值由 M2 smoke 实测吞吐定：**实测 slowdown 1.20×**（FTC 102.5s vs
LA 123s / 2048 步），远低于 4× 预算 → **interval=4 保持**；`--la-max-anchors` 64→**128**：
t287 动态步数上限 `max(200, 2×num_gates)` 使长 episode 可达 600-800 步，64 上限只覆盖
前 256 步会导致 V_LA 学不到深段状态（恰是 G10 目标场景）。）

## 6. 过闸条件

| 闸门 | 判据 |
|------|------|
| G1 | 训练中 swap_ratio >1.05 报警、>1.10 回滚（预算锚监控列已有） |
| G2 | LA287 NAM SWAP 不劣于 p0t287 起点（分段 5-9/10-14/15-19q） |
| G5 | KL(π_p0t287‖π) 均值 ≤ 0.05-0.1（超阈降 lr 或早停） |
| G6 | `pytest test/ -q` 全绿 |
| G7 | vla_loss 持续下降、无 NaN/发散 |
| G8 | 2k 步 smoke 实测 slowdown ≤4×（否则 interval 4→8 重测） |
| **G9（主判据）** | 同 ckpt 上 **beam5(la) ≥ beam5(route)**（NAM 混合精度） |
| **G10（关键判据）** | **beam5(la) TRUNC ≤ 2/19**（p0t287 beam5 为 7/19——beam 发散是否被 V_LA 修复） |
| 完成率 | argmax 完成率不劣于 p0t287 |

**成功定义（分层）**：
- 底线：LA287 argmax ≥ p0t287 argmax（0.2237）且 beam5(la) 修复发散（G10）；
- 主判据：G9 成立（V_LA 是更好的打分器）；
- 拉伸：LA287 beam5(la) ≥ SABRE（0.2461）；
- 归因：LA287 − FTC287 = beam 纯贡献（扣除"继续训练"效应）。

## 7. 风险登记

| 风险 | 缓解 |
|------|------|
| KL 锚定微调退化（t287sh 先例） | 本轮奖励/观测零变化，失败主因不存在；G5 超阈早停；FTC 对照隔离 |
| V_LA 乐观偏置 | 独立头不碰 PPO 基线；clip_return=50 有界；K=2 浅深度；G7 监控 |
| 吞吐爆炸（31 边 t287 比 176 更贵） | G8 硬闸；interval/max-anchors 双阀门；anchors 仅 routing phase |
| beam5(la) 仍发散 | V_LA 在 p0t287 轨迹分布上训练，对游走轨迹分布外状态仍可能误估——G10 直接测量；若失败，下一步加推理侧预算约束（eval 版 P1-a） |
| 微调步数不足（100k vs 200k） | KL 微调是增量学习，100k 为 0915 §8 S1 同款预算；若 agr/vla 曲线未收敛可续训（ckpt resume 语义已验证） |
| p0t287 起点本身游走（3 条电路） | LA 不承诺修复起点缺陷；游走电路的 beam 行为单独列入诊断 |

## 10. 一句话总结

p0t287 的 NAM 证据表明：0915 结构注入让模型"知道"什么是好边（深电路 SWAP 换保真度
真实生效），但推理端裸 beam 发散（7/19 TRUNC）证明 **beam 必须进入训练闭环**——
在 0915 奖励/观测/训练集全面冻结的底座上，以 KL 锚定微调注入训练期 beam expectimax
（V_LA 多步价值头），用 FTC 对照隔离"继续训练"效应，主判据 beam5(la) ≥ beam5(route)
且修复深电路发散，目标 argmax 守住 0.2237 底线并借前瞻规划把"暴力绕路"变成"少 SWAP
的聪明路径"。
