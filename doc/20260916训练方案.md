# 训练方案：Training-time Beam Lookahead + Multi-step Critic（2026-09-16）

> 目标：解决 **train-inference mismatch**——训练目标是单步策略梯度，推理目标是 beam search
> 的多步最优，导致 argmax 无法兑现噪声感知（强异构下 R3b argmax 0.1845 反输 SABRE 0.1962，
> beam5 才 +10.9%）。核心动作：训练期引入 beam expectimax 展开训练 **V_LA 多步价值头**，
> 第一版不做蒸馏（蒸馏推迟到 v2）。
> 方法论约束（沿袭 0915）：**价格冻结**（调权重已三次证伪）；**单变量纪律**（beam 机制
> 与 P0 观测/奖励改动隔离归因）；**先 SWAP 后噪声**（分阶段必要性见 §2.1）。
> v1 训练基于 tianyan176_20q 拓扑（R3b 主场，配方已知稳定）；噪声阶段（v3）迁移 tianyan287_20q。

## 1. 问题定义与现状诊断

### 1.1 核心根因：训练目标 ≠ 推理目标

```
训练：  s_t → GNN → PPO Actor → 采样动作 → r_t          （单步、无前瞻）
推理：  s_t → Actor top-K → clone×K → V(s') → beam 选优   （多步、max 算子）
```

SABRE 的 heuristic `H = H_front + W·H_extended` 天然为 lookahead 服务；而当前 PPO 策略
从未针对"搜索式决策"训练——Beam Search 只能重新组合 Actor 已学到的东西，因此
beam 有提升（+2.8% v2 口径）但难超 SABRE。

### 1.2 当前基线（v2 混合精度 T=64/32/16，NAM 19 条）

| 口径 | 模型 | Fid mean | SWAPs | 备注 |
|------|------|----------|-------|------|
| v2 混合精度 | SABRE | **0.2110** | 45.1 | 深电路全面领先 |
| v2 混合精度 | R3b_beam5 | 0.2052 | **45.0** | SWAP 持平已达成；5-9q 段领先 |
| 强异构 v2 | R3b_beam5 | **0.2175** | 45.0 | +10.9%，胜局 10/19 |
| 强异构 v2 | R3b argmax | 0.1845 | — | **感知价值依赖推理期搜索** |

### 1.3 已证伪路径（为何选 beam lookahead 这条路线）

| 路径 | 结论 |
|------|------|
| 调奖励权重 | 三次失败（t287-v1 崩塌 / t287-v2 退化 / t287sh 微调退化） |
| 观测扩维单独上 | R5a 隔离实验：特征无罪，但同样退化（种子级失稳主导） |
| 扁平 SWAP 惩罚加价 | swap_cost 扫描直接证伪（见 §2.2-Q1） |
| 推理端 beam only | train-inference mismatch 仍在，增益不稳健（3 种子符号翻转） |

## 2. 战略决策记录

### 2.1 先 SWAP 后噪声：分阶段必要性（定稿：必须分阶段）

| 证据 | 内容 |
|------|------|
| 三次联合训练失败 | t287-v1/v2 崩塌退化、t287sh 微调退化（0915 §1 记载） |
| R3c-v1 vs v2 对照 | 从零全程混合失败；坡道课程成功——序贯学习是必要条件 |
| D2 信噪比审计 | xtalk 调度奖励占回报 **0.02%**——联合训练时噪声信号数值上不在梯度里 |
| R3b 成功路径 | routing 模式（噪声盲观测+噪声定价）先达成 SWAP 持平，边噪声选择自发涌现 |

**澄清**："先 SWAP"≠"无噪声"——R3b 配方本就含 `eta_swap_err·3·e_edge` 边感知定价。
分阶段含义：第一阶段优化**路由能力**（完成率+SWAP 效率+距离势函数）；第二阶段
（0915 P0）在已收敛策略上让噪声项成为 tie-breaker。

**beam 不改变该结论**：beam 放大的是"多步回报的可预见性"，不改变噪声项的量纲占比
（D2 的 0.02% 问题原样存在）。beam 治"前瞻不足"，治不了"信噪比不足"。但 beam 让
第二阶段更强：P0-c 把噪声写进 Φ 后，V_LA 的 expectimax 目标会让"现在选脏边→后续级联
代价"的长链后果进入价值函数——**前瞻训练与噪声结构注入互补，不混在同一版归因**。

### 2.2 关键问答复盘（2026-09-16）

#### Q1：能否通过调大 SWAP 惩罚优化 SWAP 数？——不能，已被专门实验证伪

| 实验 | 结果 |
|------|------|
| swap_cost 扫描（train.md L3056-3073） | {0.5,1.0,2.0}×100k 步：平均 PPO≈29 仍高于 SABRE≈24，**惩罚越大有时越差**；同时误伤"改善布局的虚拟 SWAP"与"解锁门的关键 SWAP"，布局变差、路由期 SWAP 反增 |
| ph2v4→ph2v5（L3743-3811） | swap_cost 0.5→1.5：SWAP 43→36 降了，但 10q/12q 保真度优势（+7.0%/+18.3%）**全部丧失** |
| 方法论层（0915 §1） | "改信号，不改价格"铁律 |

根因：扁平惩罚分不清三种 SWAP（解锁门的关键 SWAP / 改善布局的虚拟 SWAP / 震荡无效
SWAP），前两类被误伤。SWAP 差距本质是**初始布局质量 + 跨层前瞻规划**，不是定价偏差。

**前提更新**：NAM v2 口径 R3b_beam5 SWAPs 45.0 ≤ SABRE 45.1——**SWAP 持平已达成**，
v1 不需要再"压 SWAP"，用 G1/G2 守住持平线即可。若未来要再压，正确杠杆是结构化的：
预算锚 P1-a（超预算才罚）、受益门控（只罚不降距离/不解锁门的 SWAP）、beam 前瞻。

#### Q2：trunc 压不到 0 是训练次数不够吗？——不是，三类结构性成因，堆步数无效

| 类型 | 机制 | 解法 | 状态 |
|------|------|------|------|
| 震荡型 | 来回 SWAP 卡死 | 死锁掩码 + no_progress_limit | ✅ 已解决（train.md L1993-2053） |
| 预算型 | 深电路 200 步物理不够（残余截断差几颗门） | 步数预算 × 每步有效率 | ⚠️ 与训练次数无关 |
| 能力型 | 策略找不到解锁路径，游走至触发反游走 | **前瞻能力**（beam lookahead 主攻） | 🎯 v1/v2 方向 |

反证：tianyan 60q ~300k 步仍 76.7% 截断（根因是终端信号折扣消失 `0.9405^800≈2.4e-18`，
credit assignment 断裂，非样本量）；R2（无 shaping）58% 截断失败 vs R3 加 Φ 后 33%→15%
（结构修复有效）；R3b trunc 曲线 ~15% 进平台期（结构性极限特征，样本不足则曲线应仍在降）。
另：训练期 10-15% trunc 部分是 `no_progress_limit` 的**设计使然**（把无限震荡转为有界
惩罚信号），eval 完成率才是真判据。

### 2.3 决策点定稿（已确认）

| 决策项 | 定稿 | 落选原因 |
|--------|------|---------|
| v1 拓扑 | **tianyan176_20q** | t287 从零训练已两次失败，新机制+新拓扑风险叠加 |
| BASE 对照 | **要，与 v1 并行**（种子配对） | 已知 40-60% 种子失稳率，无配对则 LA 贡献无法与种子运气区分 |
| 吞吐预算 | **先 smoke 实测再定**（G8） | interval=4 或 8 由实测 slowdown 数据决定 |
| 蒸馏 | **v1 不做，v2 再做** | 单变量纪律：先证明多步 critic 是更好的打分器，再蒸馏进 actor |

## 3. 融合框架：0915 结构注入 × 束搜索前瞻

### 3.1 beam 与 0915 各组件的交互关系

| 0915 组件 | 与 beam 的关系 |
|-----------|---------------|
| P0-a per-edge 噪声特征 | 提升 actor 的 top-B 候选质量（beam 展开的原料） |
| P0-b d_noise 保序距离 | 进 SABRE 特征与 Φ → beam 的 r_c 自动继承（打分口径一致） |
| P0-c Φ 扩展（E_err/X） | **beam 放大器**：V_LA 的 expectimax 目标含多步 Φ 差分 → 噪声长链后果进入价值函数 |
| P1-a 预算锚 | 超预算惩罚在奖励里 → beam Q 值自动计入，detour 探索被预算软约束 |
| P1-b KL teacher | 与 beam 正交，v3 微调期继续用 |
| **P2-a fid-critic beam** | **被 V_LA 取代**（S4 挂账关闭，见 §3.2） |

### 3.2 关键架构决策：V_LA 取代 fid-critic（S4 挂账关闭）

| 对比项 | critic_fid（0915 P2-a 原方案） | V_LA（本方案） |
|--------|------------------------------|---------------|
| 目标语义 | 代理目标（终端 fidelity 回归） | **原生目标**（expectimax 多步回报，恰为 beam max 算子所需） |
| 训练信号 | 需短 phase-2 专门训（零初始化后在 R3b 配方下从未训练——挂账"未竟"） | 每 rollout anchor 步自动产生，不存在"从未训练"问题 |
| 与奖励口径 | 另一套标定 | 复用已标定奖励（见 §4.2 打分式） |

### 3.3 阶段路线图

```
v1（本轮）  tianyan176 · R3b配方 + V_LA多头 + beam expectimax（无蒸馏）
            目标：beam5(la) > beam5(route)；产出基础设施 + agreement 基线
v2（下轮）  tianyan176 · + beam distillation（λ_d→0.5）
            目标：argmax ≈ beam5，闭合 train-inference gap
v3（噪声轮）tianyan287 · 0915 P0-a/b/c/d + P1-a/P1-b 全套，beam 机制全程开启
            目标：噪声/串扰感知（V_LA 兑现长链信用）
```

| 阶段 | 拓扑 | 优化目标 | beam 机制 |
|------|------|---------|----------|
| v1 | tianyan176_20q | 路由能力（SWAP/完成率） | V_LA 头 + 训练时 expectimax |
| v2 | tianyan176_20q | 路由能力 + 前瞻内化 | + 蒸馏 |
| v3 | tianyan287_20q | 噪声/串扰（KL 锚定微调） | 全程开启 |

v1 单独一版的必要性（G3 单变量纪律）：beam 是训练算法级改动，必须与 P0 观测/奖励
改动隔离归因；且在信号最干净的路由任务上验证吞吐/稳定性/agreement 基线。

## 4. v1 详细设计（本轮实施，无蒸馏）

### 4.1 机制

```
训练期 rollout（anchor 步：routing phase，每 --la-interval 步一次，episode 内 cap）：

  s_t ── GNN ──► Actor logits ──► top-B 候选 SWAP
                       │
           ┌───────────┴───────────┐
           ▼      (env.clone × B)   ▼
     depth 1: r¹_c, s¹_c ────► 再展开 top-B（depth K=2）
           │                            │
           ▼                            ▼
    叶节点批量 GNN forward ──► V_LA(s_leaf)     ← Multi-step Critic
           │
   Expectimax 回溯：Q(a)=r+γ·max_{a'}Q(a')，done/trunc 节点 Q=r_c
           │
   ┌───────┼──────────────┐
   ▼       ▼              ▼
 la_val  la_act        agreement
（V_LA 回归目标）（诊断）  （actor-beam 一致率，v2 蒸馏空间量化）
```

PPO 本体（采样动作、GAE on v_route、v_route 基线）**完全不动**——lookahead 只以
附加 value loss 和新价值头的形式注入。

### 4.2 数学形式

**V_LA 回归目标（expectimax）**：

```
V_LA(s_t) ← max_{a∈topB} [ r(s_t,a) + γ·V_child(s_{t+1}(a)) ]
V_child(s) = 0                     （s 为 done/truncated）
           = V_LA(s)               （s 在 depth K 叶节点，自举）
           = max_{a'} Q(s,a')      （中间节点，递归展开）
```

**打分式（复用已标定奖励，不另造启发式 scorer）**：

```
Score(s_c) = r_c + γ·V_LA(s_c)
```

用户建议的 `αD_front + βD_future + ηT_critical + μC_xtalk + νE_gate` 五项**已在 r_c 里**
（势函数 Φ shaping、gate_base、eta_time/eta_xtalk_par 调度项、eta_swap_err 边噪声定价，
R3/R3b 已标定），`λ·V_φ(s)` 项即 V_LA 头——零新增权重需标定。

**为何不改 PPO advantage 公式**：用户原始公式 `A_t^LA = Σγ^k r_{t+k} + γ^K V(s_{t+K}) − V(s_t)`
中，若 beam 路径是 expectimax（max）而 V(s_t) 是在策期望值，二者估计的不是同一量
（max-return vs E_π-return），直接相减注入系统性乐观偏置。实现改为：v_route 照旧
on-policy GAE（稳定性的锚），新增独立 `critic_la` 头回归 expectimax 目标——**V_LA
本身就是 Multi-step Critic**，且独立头不污染 PPO 基线。

### 4.3 预期管理（诚实预期）

v1 的收益在**推理侧**（beam5(la) > beam5(route)），argmax 不应有显著变化（actor 未被
触碰）——argmax 提升是 v2 蒸馏的任务。v1 的产出：
1. 验证过的 beam-in-training 基础设施（吞吐、稳定性、agreement 指标）；
2. 一个语义正确的 beam 打分器（取代从未训练的 critic_fid）；
3. actor-beam agreement 基线曲线（v2 蒸馏空间的量化依据）。

## 5. v2 / v3 锚定（本轮不实施，仅定接口）

### v2（蒸馏）

- CLI：`--la-distill-lambda 0.5 --la-distill-ramp 0.6`（进度比例内 0→0.5 线性爬满）；
- Loss：`L = L_PPO + λ_d·(−log π(la_act|s))`（expert iteration 范式；λ_d≤0.5 防 entropy 塌缩）；
- 主判据：`LAD argmax ≈ 自身 beam5`（gap 闭合）且 ≥ R3b_beam5 0.2052；
- 机制候选（届时按 G9/agr 数据定）：显式蒸馏 loss / beam 动作直接采集数据 / 混合。

### v3（噪声阶段）

- 内容：0915 §2 P0-a/b/c/d 全套 + §4 P1-a/P1-b 双保险（基础设施已建成：CLI 已有
  `--edge-noise-features/--beta-noise/--w-err/--w-xt/--w-xt-swap/--noise-hetero/--qasm-stage-cap`）；
- 路径：KL 锚定从 v2 模型微调（EdgeActorCritic 权重跨拓扑可移植——edge_mlp 按边共享
  参数，29→31 边仅 P0-a 扩维的输入层随机初始化）；
- beam 机制全程开启：V_LA 在含噪 Φ 下继续训练——"beam 放大噪声长链信用"的兑现点；
- 过闸：G1-G6 + 0915 §7.5 V1-V5。

| **BASE1** | R3b 配方逐字复跑（无 LA），种子配对 | argmax / beam5(route) | 种子级对照 |
| **LA1**（v1） | BASE + `--la-beam 3 --la-depth 2 --la-interval 4` | argmax / beam5(route) / **beam5(la)** | 隔离 multi-step critic 贡献 |
| SABRE | — | — | 基线（`--baselines --no-greedy --no-random`） |

**成功判据**：
- 主判据（G9）：`beam5(la) ≥ beam5(route)` 同 ckpt 对比（NAM，v2 混合精度 T=64/32/16，seed=42）；
- sanity：LA1 argmax ≈ BASE1 argmax（差异应仅为种子噪声）；
- 完成率（G10）：不劣于 BASE；
- trunc 诊断：beam5(la) 的预算型/能力型截断分类统计 vs BASE——定量回答"前瞻机制消灭了哪类截断"；
- v2 go/no-go：agr 曲线 + beam5(la)−argmax 差值（蒸馏空间量化）；
- 拉伸目标：beam5(la) 缩小与 SABRE 的保真度差距（0.2052 → 逼近 0.2110）。

## 10. 一句话总结

beam-only 推理已证明 lookahead 有价值但不稳健（train-inference mismatch 未闭合）；
v1 用训练期 beam expectimax 把"多步前瞻"注入独立 V_LA 头（不碰 PPO 基线、价格全面
冻结、单变量隔离），先证明 multi-step critic 是更好的打分器，v2 再蒸馏进 actor 闭合
argmax 缺口，v3 带着完整前瞻机制进入噪声阶段（0915 P0 结构注入）——三阶段各治一个
已定位的根因：前瞻不足（v1/v2）→ 信噪比不足（v3）。
