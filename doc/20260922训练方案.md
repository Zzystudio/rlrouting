# RL 路由 vs SABRE 差距的系统分析（2026-09-22）

> 状态：分析定稿。背景：时钟化管线（Clocked Routing v1）在随机电路（t287_test）
> fidelity 反超 SABRE +27%~60%，但在结构化电路（in-dist 50 / NAM）明显落后
> （swap 2-6×、fidelity 0.78-0.92×）。本文件从架构、奖励、训练集、训练算法
> 四个维度拆解差距根源，并给出依证据排序的路线。

## 0. 事实基线（本轮全部实验证据）

| 指标 | SABRE（完整：SabreLayout+SabreSwap+multi-trial） | C0+mimic（当前最优） |
|---|---|---|
| t287_test（随机） | fid 0.070-0.073 | fid 0.090-0.093（**+27~60%**） |
| in-dist 50（结构化） | sw 20.9, fid 0.344 | sw 85.8, fid 0.267（0.78×） |
| 布局实验后 t287 | fid 0.24-0.62（很多 0 swap） | sw 8-35, fid 0.03-0.28（远输） |
| mimic 单独路由能力 | 1.0× | 1.1×（随机）/ 1.2×（结构化，0b 口径） |
| best-of-5 trial 收益 | — | 仅 7%（compare_sabre_trials） |
| ε-tie-break + best-of-N | — | 硬电路无效（pauli 489 swap、tof_tower 全败） |

**核心事实**：mimic 路由本身只有 1.1-1.2× 差距；6.6× 灾难是时钟化执行伪影
（swap 锁窗内级联）；布局优化后完整 SABRE 基线大幅变强而 mimic 反而倒退
（识别不出"布局已好，只需执行"）。

## 一、架构设计

| 机制 | SABRE | RL | 影响 |
|---|---|---|---|
| 决策 | 每步枚举全部候选边，**实时精确计算**打分（front+ext 距离、decay） | 一次前向共享 edge_mlp 摊销排序 | SABRE 是算法（每次重算），RL 是摊销函数 |
| 状态演化 | 精确 front 层补货/门应用时序 + 随机 tie-break + **best-of-N 重启** | 无记忆策略，靠状态表示 | 重启/随机性是逃出简并盆地（分数并列）的机制，RL 没有 |
| 感受野 | — | GNN 2 层（2-hop），全图靠手工特征广播兜底 | 真正干活的是特征工程，天花板=特征上限 |
| 动作空间 | 与算法语义兼容 | 时钟化给了 SWAP/EXEC/SKIP+锁的自由度 | 富表达力需训练分布覆盖；未覆盖时反噬（锁窗级联） |
| 价值函数 | 不需要 | V(s) 是 PPO/GAE/beam 的支柱 | **V 失准主动有害**（la287core beam>argmax swap；C0 critic 在 mimic 分布 OOD） |

**要点**：RL 在"摊销搜索"一个算法。若打分完整在特征里，理论上能学"argmin"
这个平凡函数——但 0b 证明特征不完整（decay 修复后仍有 ext 集/执行状态耦合
残差），mimic 上限 1.46× NAM。函数里都没有的信息，NN 学不到。

## 二、奖励函数

1. **奖励排序本身正确**：EXEC +0.11 > SKIP −0.03 > SWAP −1.19；C3v2 用同样
   奖励在正确分布上自学到锁等待——**奖励无罪**。
2. **长程换手收益的信用衰减**：swap 价值 10-30 门后兑现，GAE 有效视界
   γλ≈0.94 ≈ **17 步**（自适应 λ 到 0.998 ≈200 步）；SABRE 用 ext-set 前瞻
   （后 20 门×0.5）把信用直接算进每步即时评估——**它没有信用分配问题**。
3. **混合目标的结构冲突**：进度+swap 价+时间/并行+Φ 距离塑形在随机电路同向、
   在结构化电路冲突（尽早完成深串行链需要大量 swap）→ 混合域最优解天然非
   swap 平价。
4. **保真度终端信号对但信噪比不足**：T=16 时 episode 估计 σ≈0.05-0.1，深度
   噪声电路上调度间真实差 < 估计方差，梯度被淹没（C3/C3-v2 都因此回归）。
5. **近似噪声价是代理幻觉**：标定被污染 → 过串行化 → makespan↑ → 退相干↑；
   任何 routing 模式附加奖励都拖离 C0 的 makespan 最优调度。

---

## 三、训练集（最大单一因素）

1. **分布错配（决定性）**：训练=随机电路为主 + NAM-mix 30%；评估 in-dist/NAM
   结构化。直接证据：**C3v2（mimic 分布训练）无守卫≈C0+守卫；C0（无此分布）
   同电路爆炸 6.6×**——同样奖励、同样网络、只差分布。
2. **难度未覆盖**：深度结构化电路（tof_10/gf2_6/wadd，100-300 门串行链）训练
   截断率 7-28%，模型从未见过完整解，只收截断惩罚。
3. **结构化数据混入也不等于可学**：正确解需"临时变差分数"（搬远路），奖励
   教不了、蒸馏教不了（BC 分布漂移，NAM 直接 330+）。

## 四、训练算法

1. **问题结构偏向算法而非 RL**：routing 是硬离散组合搜索（确定性环境、可用
   精确启发式、支持随机重启）——PPO 的 on-policy 采样引入无意义探索，熵塌缩
   后收敛到混合奖励最优点而非 swap 最优点。SABRE 的贪心+best-of-N 重启是这
   类问题更高效的优化器。
2. **热启动诅咒**：LA287core→C0→C1/C2/C3 每次续训都退化（漂移+混合奖励摧毁
   继承路由）；KL 锚定只减缓（6→3.7×）不修复。
3. **蒸馏天花板**：demo 只教 SABRE 轨迹上的状态，评估在自身轨迹上；深电路
   偏离指数放大。DAgger 式 on-policy 教师查询理论上更好，但 SABRE 选择依赖
   自身轨迹，教师非状态无关。
4. **beam/价值蒸馏**：V_LA 基于 depth-2 beam 目标 + 自身 V 引导（循环），
   实证 beam 反而增 swap。

## 五、本质：RL 的真实价值被搞错了位置

| 组件 | 来源 | 表现 |
|---|---|---|
| 换手路由 | SABRE 启发式（mimic 是其贪心近似，1.1-1.2×） | **RL 结构性输，且难以反超** |
| 调度（时序/并行/makespan） | C0 的 RL 学习 | **t287 +27%，RL 真正赢的地方** |

"+60% t287 胜利"分解：SABRE 的路由（mimic）+ RL 的调度——不是 RL 路由打赢
SABRE。RL 的真实贡献是**调度器，不是路由器**。

---

## 六、依证据排序的路线（下一步方向）

1. **不与 SABRE 拼路由——嵌入它（SABRE 脚本路由）**：完整 SABRE（布局+换手+
   multi-trial）预先路由，时钟化只控 EXEC/SKIP 时序。布局收益直接继承、swap
   全平价（0-swap 电路也 0 swap）、RL 调度（+27%）在平价路由上为纯增益。
2. **RL 在路由上的合法战场 = 噪声感知偏离**：选稍远但更安静边/时序换 fidelity
   （SABRE 噪声盲）——前提是保真度信号可靠化（解析代理代替采样轨迹 + log-ratio
   + KL 锚定，防漂移）。
3. **训练集**：难结构化族补到"能完成"（先解决截断再谈学习）；或分域训练。
4. **算法**：routing 的离散确定性问题上，搜索式 RL（MCTS/树搜索蒸馏）比 PPO
   采样对口——作推理算子或教师，不进 rollout。
